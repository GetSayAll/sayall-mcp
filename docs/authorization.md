# 授权模型

## 默认关闭

本地 Agent 访问在缺少设置文件和首次安装时均为关闭。用户必须在无线麦SayAll.app 内主动开启；仓库、Agent 或 Helper 均不能自行开启访问或创建授权。

## 每客户端授权

每个客户端拥有独立的：

- client ID；
- 256-bit 随机访问令牌；
- 用户可识别的显示名称；
- 固定只读范围 `transcripts.read.all`；
- 创建时间和可选撤销时间。

明文令牌只在创建时显示一次。无线麦SayAll.app 只在 `access.json` 中保存令牌和 Helper 路径的 SHA-256 哈希，无法恢复明文令牌或原始 App 路径；令牌丢失时应撤销旧授权并创建新授权。路径指纹仅用于识别 App 改名、移动或旧授权缺少路径信息，并提示重新连接。

## 本地状态

授权状态由 App 管理：

```text
~/Library/Application Support/RemoteMic/MCP/v1/access.json
```

文件使用 `schemaVersion: 1`，目录权限为 `0700`，文件权限为 `0600`。Helper 启动和每次工具调用都会重新读取状态，因此关闭总开关或撤销客户端无需重启现有 MCP 连接即可生效。

## 撤销与关闭

- 撤销单个客户端只影响对应凭据；
- 关闭总开关立即拒绝全部客户端，但不删除授权或历史；
- 总开关关闭时，用户仍可在 App 内查看并撤销授权；
- 重新开启不会恢复已经撤销的授权。
